# OBS Filters by Yasunari Murayama - Brand Direction

## Brand Family

Parent brand:

- `OBS Filters by Yasunari Murayama`

Plugin products:

- `Temperature + Tint`
- `Colorist Tone`
- `SkinSoft`

## Visual Direction

The family should feel like premium tools for streamers, camera users, editors, and colorists inside OBS. The design should be clean, technical, and cinematic without copying OBS, Adobe, DaVinci, TikTok, or beauty-app visual language.

## Icon Concepts

`OBS Filters by Yasunari Murayama`

- Camera/lens plus filter stack or color spectrum.
- Role: parent brand mark for website, pack installer, documentation, and storefront.

`Temperature + Tint`

- Cold-to-warm symbol, cyan to amber.
- Optional magenta/green tint accent.
- Role: clear white-balance/color correction identity.

`Colorist Tone`

- Tonal curve, waveform, or layered luminance bands.
- Role: live tonal shaping without promising a graphical curves editor.

`SkinSoft`

- Soft face contour, skin mask, or glow field.
- Role: controlled skin smoothing and skin selection.

## Shared Palette

- Charcoal / near-black for typography and contrast.
- White / light neutral for product pages and package backgrounds.
- Electric cyan for technical/cool color work.
- Warm amber for temperature/warmth.
- Magenta accent for tint/colorist identity.
- Skin-peach accent for SkinSoft.

## Production Notes

This first pass is a raster concept sheet. Before shipping, convert selected marks into deterministic vector assets:

- SVG logo marks.
- 1024x1024 app/package icon PNG exports.
- 512x512, 256x256, 128x128, 64x64 icon exports.
- Dark and light variants.
- Individual product lockups.

Use exact text in vector tooling rather than relying on generated raster text for final packaging.
